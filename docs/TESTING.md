# 测试与验收

适用版本：[README当前版本](../README.md)。维护作者：相安（3199912548@qq.com）。本次本地执行结果见 [VALIDATION.md](VALIDATION.md)。

## 已自动检查的范围

运行 `npm run check`：

- 版本同步工具的幂等性、无效版本拒绝、UUID/API依赖保护及缺失文档标记时不写入。
- 发布流程的远程标签与提交核对、草稿续传、已发布版本保护、摘要错误拒绝、变更记录提取和凭证目标限制；这些测试使用受控假API，不访问GitHub。
- Python构建的同输入可重复性、测试文件排除、嵌套安装包与授权说明一致性、校验清单，以及版本不一致时拒绝构建。
- 文档严格UTF-8解码与本地链接目标。
- 所有行为包脚本的语法与本地模块导入/命名导出。
- 全部 JSON 可解析，package/lockfile、BP/RP清单头部/模块/互相依赖、包名称与界面版本一致。
- 英文/简体中文各3163个语言键完整、无重复，格式化占位符及静态调用参数数量一致；全部发货文本严格UTF-8解码。
- 乱码/替换字符/异常控制字符、Minecraft格式码、静态语言引用、RawMessage错误字符串化及已修复静态英文回归检查；使用合成错误样本验证检查器会拒绝损坏数据。
- 直接加载实际礼包菜单/事件反馈代码，验证第46刻清空标题与副标题、重复领取最新计时、不同玩家隔离、陈旧回调、离线释放及同ID重连。
- 礼包领取后接传送、挂机或领地标题不会被旧任务清除；单个HUD接口异常不会中断其他提示与业务。
- 157种管理日志动作、动态存储分页中文显示；真实日志过滤器展示中文但提交原动作ID，技术标识与用户内容保留。
- 搜索页全部61个实际条目的目的地与上级菜单显示、中英文切换、匹配词和跳转数据保留；原作搜索算法和多语言词库断言继续通过。
- 中英文时间消息渲染、礼包编辑框长冷却和自定义游玩时长精确往返；诊断页不依赖英语文本判断API可用性。
- 0/86400 冷却边界，负数、小数、超范围无效输入。
- 24 小时制时间解析、游戏 06:00 起点、跨午夜与区间边界。
- 不同玩家、不同目的地及 legacy 家园的冷却身份隔离。
- 背包多格扣费、物品不足、失败退款及物品元数据保留。
- 覆盖坐标/图标保留规则和身份，删除再建获得新身份。
- 旧表单等待期间的新规则/坐标/其他家园不会被过期快照回滚；已删除目标不会复活。
- 离线删除确认期间房主上线时改删真实记录；带世代的离线删除队列不会误删同名新家园。
- 管理员在线/离线逐玩家家园规则与传送开关修改；离线队列即时叠加、上线合并、失败重试和同名重建隔离。
- 统一管理菜单接线、单家园授权作用域、撤销管理员身份后的旧表单提交拦截；普通玩家和协管员拒绝写入他人设置。
- 床按钮按开关隐藏且不影响其他按钮索引；旧按钮、等待中和坐骑实际延迟移动一刻均复查开关。
- 实际等待提示代码的聊天、标题/副标题、目的地和动作栏；即时显示、每5刻刷新、秒数变化、结束清理、单个HUD接口异常保护。
- 家园/传送点、床及TPA的等待流程；TPA双方提醒，移动/换维度/离线取消，0延时不显示等待，实际失败不误报成功。
- 一次/临时/永久授权、次数扣减、到期、撤销、跨房主隔离、离线镜像。
- 服务器与房主两层规则按顺序校验，关闭总开关/单项开关不覆盖存量房主配置、不绕过授权。
- 传送前确认窗显示实时游戏时间、授权状态、各层时段/冷却、合计费用和库存足量状态；取消确认不扣费、不传送、不启动冷却。
- 同类型两层费用按合计库存核对，不同类型费用均需足额；任一层失败不扣费。
- 30%/0%/100%税、拆分小额税余数、成功入账、失败取消、不确定预留不自动变可领取收益。
- 离线房主收益持久化、重复提交防重、收益领取的背包容量及存储失败保护。

测试详情以执行输出及 `tests/` 为准。测试使用 Node 的模拟 Minecraft 接口，不启动 Minecraft 客户端，也不证明联机网络、存盘设备或所有坐骑类型均已实测。
