# 管理员家园统一管理

维护作者：**相安** · **3199912548@qq.com**。

## 入口与角色

打开“管理工具 → 家园统一管理（管理员）”。管理员自己的“玩家工具 → 家园”菜单也提供同一入口。管理员包括本模组认可的服主与管理员，协管员和普通玩家不能进入或提交设置；表单打开后管理员权限被撤销，也不能继续保存。

原来的服主专属家园规则、税率和功能开关已下放至管理员，统一称为“服务器家园规则”。这次调整不改变服务器层与房主层的 AND 关系，也不把家园与公共传送点混在一起。

## 控制传送到床

统一管理 → 服务器家园规则、床传送与税务 → 允许传送到床。

- 升级时默认开启，兼容原有使用方式。
- 关闭后，重新打开家园菜单不再显示“传送到床”；其他按钮与操作仍正确对应。
- 已打开的旧按钮、坐骑选择、倒计时和因骑乘延后一刻的实际移动均重查开关，关闭后不可继续床传送。
- 不改变床的正常重生机制，也不影响保存的家园、传送点或其他传送功能。
- 床传送开关独立于家园规则总开关；关闭规则不会重新打开床传送。

## 编辑服务器规则与税率

同一页面可以设置附加冷却、附加物品费用、游戏开放时段、房主收费税率，以及规则总开关和冷却/收费/时段开关。默认税率仍为30%，范围0–100%。

玩家必须先通过服务器层，再通过目标家园的房主层。两层费用累加；服务器附加费用独立消耗，房主规则费用扣税后的物品仍归家园所有者，管理员代改规则不会改变收款归属。

## 逐玩家管理

统一管理 → 逐玩家管理家园权限与规则 → 玩家 → 家园。玩家列表包含在线和登记过的离线玩家；离线玩家需要已有家园镜像，没有镜像时先让该玩家上线保存一次。

| 操作 | 效果 |
| --- | --- |
| 编辑该家园传送规则 | 修改这一个家园的房主层冷却、物品费用和游戏开放时段，不影响其他家园或公共传送点。收费物品从操作管理员的当前背包选取，已有类型可保留。 |
| 启用/关闭此家园传送 | 关闭后房主、管理员和已有授权访客都不能使用此家园传送；保留坐标、规则、授权和收益。重新启用后仍需满足授权与两层规则。 |
| 管理此家园访问申请与授权 | 同意/拒绝申请，主动授予、修改或撤销一次、临时、永久权限及次数限制。 |
| 玩家全部家园授权 | 在玩家页集中查看该玩家全部家园的申请和授权，仍按每个家园分别保存。 |

管理员可以在规则功能暂停时预先编辑家园规则，保存不会启用已关闭的功能。房主自己的规则编辑入口保留；房主不能修改管理员设置的传送开关，也不能编辑被服务器暂停的规则项。

## 授权边界

普通房主继续管理自己的申请与授权；管理员可代管任意玩家的家园。管理员身份本身不提供自动访问权，需要传送他人家园时仍应明确获得房主或管理员授予的有效授权。管理员可以明确给自己授权，操作会记录授予者。

临时权限使用现实分钟，从批准时开始；次数只在真实传送成功后扣除。单家园传送被关闭时，已有授权保留，不消耗次数，但临时权限的现实有效期仍继续计时。规则总开关不能绕过单家园开关和访问授权。

## 离线修改与升级

离线家园修改先保存到世界中的管理队列，目录和传送立即读取修改后的值。玩家上线后按家园身份合并到真实家园属性，不用旧镜像覆盖整个玩家家园。删除后重建的同名家园视为新的目的地，旧管理修改、旧授权与旧冷却不会误套用。

保存失败会报告失败并保留已持久化的待同步修改供重试。升级保留原包 UUID、原规则、授权、收益和税务累计；请先备份世界，再导入[当前版本](../README.md)并确认行为包与资源包均为新版。礼包提示清理和中文日志沿用2.5.1修复；2.5.2将玩家工具配方调整为3个任意种类原木无序合成，家园管理流程沿用现有规则。
